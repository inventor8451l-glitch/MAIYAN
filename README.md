# MAIYAN — Luxury Resort Website

A responsive Next.js 14 / TypeScript / Tailwind website for MAIYAN in Laikipia, Nanyuki, Kenya.

## Run locally
1. Install Node.js 20 LTS.
2. Run `npm install`.
3. Run `npm run dev` and open http://localhost:3000.
4. Run `npm run build` before deployment.

## Deploy on Netlify
Import this GitHub repository in Netlify. The included `netlify.toml` configures the Next.js build. Netlify should detect the Next.js runtime plugin automatically.

## Before going live
- Replace `reservations@maiyan.example` with MAIYAN's verified booking email.
- Replace `https://maiyan.example` in metadata and robots.txt with the real domain.
- Replace remote Unsplash placeholders with licensed MAIYAN property photography.
- Verify villa inventory, amenities, location details, contact information and all claims with MAIYAN.
- The reviews section was removed rather than publish unverified testimonials.
- Original video files are not in this commit; the website uses a photo-based hero and works without them.

This is a deployable starter website, not a verified production site. Run a build and complete content, accessibility and device testing before public launch.
